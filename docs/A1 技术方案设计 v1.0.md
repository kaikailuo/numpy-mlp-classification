## 0. 决策摘要与适用边界

### 0.1 已冻结的决策（FROZEN）

1. **任务范围**：一个通用的 NumPy 多层感知机（MLP）图像分类实验框架；分别完成 MNIST、CIFAR-10；覆盖分类基础题，以及损失/正则化、优化方法两类附加实验。课程原题的数据集要求是 **MNIST 或 CIFAR-10**，双数据集是本项目主动扩展。
2. **技术限制**：神经网络参数、前向、BP、损失/梯度、优化器、评估计算全部由 NumPy 实现。不得使用 PyTorch、TensorFlow、JAX 的模型、自动求导或优化器代替核心实现；Matplotlib 可用于可视化、pytest 用于测试。
3. **开发栈**：Python **3.12**；NumPy、Matplotlib、pytest；用 **uv** 管理环境和锁文件；配置使用 Python 标准库支持的 **TOML**，日志使用 **JSON/CSV**。项目运行默认 CPU，不依赖独立 GPU 或学校服务器。
4. **数据协议**：MNIST 官方训练 60,000 → 训练 55,000 + 验证 5,000；CIFAR-10 官方训练 50,000 → 训练 45,000 + 验证 5,000；两者官方测试集均保留 10,000。不从测试集拟合预处理参数、调参、选模型。
5. **数学约定**：批优先（row-major samples）；`X: (B, D)`，`W: (D_in, D_out)`，`b: (D_out,)`，logits: `(B,10)`；`loss` 按 batch 样本取均值；梯度同样包含 `1/B` 且**只除一次**。
6. **基准模型**：MNIST `784→128→64→10`；CIFAR-10 `3072→256→128→10`；隐藏 ReLU + Kaiming normal；输出 logits，推断时 Softmax；Cross-Entropy，Mini-batch SGD。默认初始 batch size `128`，具体学习率与训练轮数在真实基准计时后调整。
7. **正确性门禁**：无有限差分梯度检查、Tiny-set Overfit、基本数据隔离与端到端 smoke test 的通过证据，禁止启动正式矩阵实验。
8. **实验与交付**：共享实验配置、模型实现与数据切分；一组运行生成一组可追溯记录；先验证集对比，冻结选择后才正式评估测试集。最终交付源码 ZIP、论文式 PDF、复现说明及必要附录（GitHub 链接为辅助）。

## 3. 张量协议与公开接口（Codex 需遵守）

### 3.1 形状、精度、内存

| 对象 | 形状 / 类型 | 约束 |
|---|---|---|
| 单批输入 `X` | `np.ndarray[B, D]`, `float32` | 每一行代表一张图；不含标签 |
| 标签 `y` | `np.ndarray[B]`, 整数 | 值域 `[0, 9]`；训练默认整数标签而非存储 one-hot |
| 第 `l` 层权重 `W_l` | `[D_in, D_out]`, `float32` | `Z=X@W+b`，不同于课件按列样本展示的写法，但数学等价 |
| 偏置 `b_l` | `[D_out]`, `float32` | NumPy 广播到 B 行 |
| `logits` / `probs` | `[B, 10]`, `float32` | logits 不做输出 ReLU；probs 只在预测与对应 loss 内部计算 |
| `grad_W` / `grad_b` | 与参数同 shape | 对**平均 batch 数据损失**求导；正则梯度另加 |
| loss / accuracy | Python `float` | 按每张样本加权汇总全量 dataset，非简单求 batch 标量均值 |
| 梯度检查 | `float64` | 与正式 `float32` 训练分离 |

如果最后一个 batch 大小不足 B，按真实 `B_actual` 求平均，不丢弃样本（基准 `drop_last=false`）。所有随机数使用显式 `np.random.Generator`，不能依赖隐式全局 seed。

### 3.2 核心对象的稳定接口（签名为设计规范，允许等价的类型注解）

```python
@dataclass
class Parameter:
    name: str                  # 唯一稳定名，例如 layers.0.weight
    data: np.ndarray
    grad: np.ndarray           # 与 data 同形；必须可清零

class Dense:
    def forward(self, x: np.ndarray, training: bool = True) -> np.ndarray: ...
    def backward(self, grad_output: np.ndarray) -> np.ndarray: ...
    def parameters(self) -> list[Parameter]: ...

class ReLU:
    def forward(self, x: np.ndarray, training: bool = True) -> np.ndarray: ...
    def backward(self, grad_output: np.ndarray) -> np.ndarray: ...

class Dropout:                  # 阶段 4 实现；训练采用 inverted dropout
    def forward(self, x: np.ndarray, training: bool = True) -> np.ndarray: ...
    def backward(self, grad_output: np.ndarray) -> np.ndarray: ...

class MLP:
    def forward(self, x: np.ndarray, training: bool = False) -> np.ndarray: ...  # logits
    def backward(self, grad_logits: np.ndarray) -> np.ndarray: ...
    def parameters(self) -> list[Parameter]: ...
    def zero_grad(self) -> None: ...
    def predict_proba(self, x: np.ndarray) -> np.ndarray: ...
    def predict(self, x: np.ndarray) -> np.ndarray: ...                # [B] integers

class Loss:
    def value_and_grad(self, logits: np.ndarray, y: np.ndarray) -> tuple[float, np.ndarray]: ...

class Optimizer:
    def step(self, params: list[Parameter]) -> None: ...

class Trainer:
    def fit(self, model, train_data, val_data, loss, optimizer, config) -> 'FitResult': ...
```

**约束**：正式训练的参数 dtype 默认 `float32`，但构造层/模型时必须允许显式选择 `float64`，以便梯度检查中的权重、前向、loss 和梯度全部维持双精度而不被悄悄转回 `float32`。`Dense.forward(training=True)` 才保存 BP 需要的缓存；验证和预测 `training=False` 不能污染下一次训练的缓存。`model.backward` 仅接收 loss 返回的 `grad_logits`；计算正则梯度的独立函数负责在 `optimizer.step` 前附加到参数 `grad`。训练循环的次序：`model.zero_grad → forward → loss.value_and_grad → backward → add_regularization_grads → optimizer.step`。所有模块按上述约定测试。

### 3.3 前向与 BP 数学约定

令每层输入 `A` 为 `(B, D_in)`：

```text
Z = A @ W + b                  # (B, D_out)
H = ReLU(Z)                     # 隐藏层；输出层直接使用 Z (logits)

dW = A.T @ dZ                  # (D_in, D_out)
db = sum(dZ, axis=0)            # (D_out,)
dA = dZ @ W.T                   # (B, D_in)
ReLU'(Z) = 1[Z > 0]            # Z == 0 处约定为 0
```

`dZ` 源自已经 batch-mean 的 loss，`Dense.backward` **不得再次 `/B`**。中间层逐层应用链式法则，先计算当前层输入梯度再反向传递；参数 `grad` 的形状/有限值必须通过断言或测试保证。

### 3.4 参数初始化

- 隐藏层使用 ReLU：`W ~ N(0, 2 / fan_in)`（标准差 `sqrt(2/fan_in)`），`b=0`。
- 输出线性层可使用 Xavier normal（`std=sqrt(2/(fan_in+fan_out))`），防止将所有非线性层视作同一个初始化规则；如为一致性选择 Kaiming 输出层，也须记录。**v1.0 固定输出层 Xavier normal**。
- 对比 Tanh 时改用 Xavier；初始化每一实验组采用指定的 `init_seed`，除非实验变量正是初始化本身。
- 不允许将全部权重初始化为 0；仅偏置为 0。

## 4. 损失、正则化、激活与优化器

### 4.1 稳定的 Softmax 和交叉熵（Stage 1 必须）

对于 `z=(B,C)`，采用逐行减最大值：

```text
m_i = max_j z_ij
logsumexp_i = m_i + log(sum_j exp(z_ij - m_i))
L_CE = (1/B) * sum_i (logsumexp_i - z[i, y_i])
p_ij = exp(z_ij - logsumexp_i)
dL_CE/dz = (p - one_hot(y)) / B
```

**禁止**直接算 `exp(logits)` 后除总和而不考虑溢出；禁止计算 `log(0)`；`one_hot` 可在 loss 内临时创建，不在数据集复制保存。评估数据损失时使用同一稳定 CE 实现。训练默认不进行概率裁剪以“修补”本可避免的溢出问题。

### 4.2 Softmax 输出上的平方误差（Stage 4）

为了与 CE 使用**同一个网络和输出概率定义**：

```text
P = softmax(Z)
Y = one_hot(y)
L_MSE = (1 / (2B)) * sum_i sum_j (P_ij - Y_ij)^2
G = (P - Y) / B                              # dL/dP
(dL/dZ)_ij = P_ij * (G_ij - sum_k G_ik * P_ik)
```

这里借助 Softmax Jacobian-vector product 计算**完整链式梯度**；绝对不能直接用 CE 的 `(P-Y)/B` 冒充 MSE 的 `dL/dlogits`。报告中将上述损失称为“Softmax 概率上的平方误差”，同时说明具体 `1/2` 和 batch mean 约定；CE/MSE 的**损失数值不可直接按大小互相排名**，应比较相同的验证指标、收敛进程与泛化表现。

### 4.3 正则化（Stage 4）

选择只对权重矩阵 `W` 正则，不对 `b` 正则；lambda 为固定系数、不随 batch 大小自动缩放：

```text
L_total = L_data + L_reg
L2: L_reg = (λ/2) * sum_l ||W_l||_F^2      ; dW += λ W
L1: L_reg = λ * sum_l sum_ab |W_l,ab|    ; dW += λ sign(W)
```

规定 `sign(0)=0` 作为 L1 次梯度。L1/L2 在损失与梯度上的实现必须配套，日志分别保存 `data_loss`, `reg_loss`, `total_loss`。正则量受网络参数量影响，**lambda 起点仅是候选，需经验证集调整**。

Dropout：仅施加在隐藏激活后，默认候选 `drop_prob=0.2`；训练 `mask ~ Bernoulli(keep_prob)`，输出 `H * mask / keep_prob`，反向使用**同一张 mask**；验证与预测恒等映射且**不消耗训练随机数**。Dropout 是训练时随机正则，与 L1/L2 有不同机制；第一轮对照各单独启用，不默认叠加。

### 4.4 优化器实现优先级

| 算法 | 优先级 | 最小更新公式/特征 | 对照关注点 |
|---|---|---|---|
| Mini-batch SGD | P0 | `θ ← θ − ηg` | 基准；无状态 |
| Momentum | P1 | `v ← μv + g; θ ← θ − ηv`，`μ=0.9` 候选 | 损失震荡/收敛效率 |
| AdaGrad | P1 | `s ← s + g²; θ ← θ − η g/(sqrt(s)+eps)` | 步长随历史平方梯度衰减 |
| Adam | P1 | 一阶/二阶指数滑动平均，**含偏差修正**；`β1=.9, β2=.999, eps=1e-8` 候选 | 自适应更新与收敛速度 |
| RMSProp | P2 | `s ← ρs+(1−ρ)g²`，按均方根缩放 | 预算允许时补充 |
| Adamax | P3 | Adam 的无穷范数变体 | 可选，不是附加题达成条件 |

所有优化器必须处理 `W` 和 `b`，并为每个参数维护独立状态；**状态 keyed by 稳定参数名**，避免把不同形状的参数或不同实验运行混在一起。`eps` 的摆放采用表中公式并记录；Adam 状态步数每次 `optimizer.step()` 更新一次。正则化在第一轮按显式加入梯度处理（即**coupled L2**），不能把 AdamW 的 decoupled weight decay 偷换成同一实验条件。

**术语固定**：`Batch GD` = 全训练集 1 次更新/epoch；`Online SGD` = 单样本更新；`Mini-batch SGD` = B=128（候选）逐批更新；Momentum/AdaGrad/Adam 都在同样的 mini-batch 条件下比较。不要把“SGD”与“Mini-batch GD”误写成天然不同的两种更新公式。

## 5. 数据读取、划分、预处理与隔离

### 5.1 数据读取（无需深度学习框架）

- **MNIST**：读取可信来源的 IDX 文件（可为 `.gz`）；检查 magic number、样本总数、图片 `28×28`、标签长度及 `[0,9]`。
- **CIFAR-10**：读取官方 `cifar-10-batches-py` 格式（五个训练 batch、一个测试 batch，`data` 为 `(N,3072)` uint8），解析官方数据中的 RGB 三通道。读取 pickle **只针对用户明确下载并核实来源的官方数据文件**，不加载来源不明的 pickle。
- 数据准备与训练分开：`prepare-data` 只校验及准备本地文件；训练时数据缺失要给出明确路径和准备说明，不暗中联网并覆盖数据。
- 不引入 torchvision、TensorFlow datasets 等作为“核心计算依赖”；使用 Python/NumPy 足够。

### 5.2 数据划分与复现

- 从**官方训练集**按标签进行固定种子的分层抽样，MNIST 挑出 5,000 验证，CIFAR-10 挑出 5,000 验证；不触碰官方 test。MNIST 的每类比例按其实际原始频数计算；保证全体样本无重复、无遗漏且验证样本数准确。
- 固定 `split_seed=20261011`；保存 `data/splits/<dataset>_split_v1.npz`（train/val 原始行号）及对应 meta JSON（样本数、类别分布、原始文件哈希、seed、算法版本）。后续所有实验**加载同一份 split**，不得各自再随机划分。
- 单独设置 `init_seed=42`, `shuffle_seed=43`, `dropout_seed=44`（初始约定）。不同重复实验使用显式列出的 seeds；**分割 seed 不随训练 seed 改变**。

### 5.3 预处理（fit/train-only）

| 数据集 | v1.0 预处理 | 避免的问题 |
|---|---|---|
| MNIST | uint8 图像展平 `(B,784)`，按批转换 float32，除以 `255.0` | 数值范围不一致 |
| CIFAR-10 | 官方 channel-first 数据恢复 `(B,3,32,32)`，按 RGB 每通道使用训练子集统计的 `mean/std` 标准化，然后展平 `(B,3072)` | RGB 顺序错误与验证/测试数据泄漏 |

CIFAR-10 的 `mean/std` 仅在训练划分上拟合，用有界内存分块计算、缓存到 split 元信息，并复用于训练/验证/测试；标准差加 `epsilon` 防止零除。保持 uint8 原数据/索引，按 batch 转 float32 和标准化，避免为 CIFAR-10 反复拷贝整套 `(50000,3072)` float32（单份约 614 MB）。当前不启用随机图像增强，保证先有纯 MLP 可控基线。

### 5.4 评估规则

- 每个 epoch 完成 train 与 validation 指标收集；**验证阶段不更新权重、不应用 Dropout、不消耗训练随机状态**。
- `best checkpoint` 的统一选择规则：**验证 Accuracy 最大 → 若并列则验证 CE 最小 → 再并列取较早 epoch**。无论训练目标是 CE 还是 MSE，都采用相同标准；报告明确该选择规则。
- **测试集一次性最终评估**：待某组候选的参数与选择标准在验证集上确定并冻结后，再对最终报告中保留的各组模型读取官方测试集；测试结果不得返回用于重新调参。
- 训练 loss 记录 per-sample 的加权均值，避免尾 batch 未满时出现 epoch loss 偏差。`train_eval_accuracy` 在 evaluation mode 下统计，避免与 Dropout 训练态的指标混淆。

## 7. 正确性验证与测试计划（先于性能）

| 测试 ID | 内容 | 阶段 1 门槛 / 后续要求 |
|---|---|---|
| T-01 | Dense/ReLU 形状、dtype、有限值；参数 `grad` 与输入一致 | 所有基础用例通过 |
| T-02 | Softmax 稳定性：大正/负 logits（如 ±1000）、每行概率和约 1、CE 有限值 | 无 `inf`、`nan`；概率有效 |
| T-03 | Dense、ReLU、融合 CE 的有限差分梯度检查 | `float64`，避开 ReLU 0 附近；满足数值误差门槛 |
| T-04 | 全链路 2→3→3 类 toy MLP 的数值梯度检查 | 每层权重/偏置的抽样参数通过 |
| T-05 | Tiny-set Overfit：可分 toy 分类数据（例如三类二维簇，每类数个点） | 训练目标明显下降、训练 Accuracy 可达 100%（固定数据与 seed） |
| T-06 | MNIST IDX 加载与划分：count/label/range/无重叠/复现 hash | 明确 55k/5k/10k；二次生成一致 |
| T-07 | 单步 SGD：给定参数/梯度的精确更新对照 | 按数值容差匹配预期结果 |
| T-08 | 输入缺失/维度不符/NaN/错误 checkpoint 报错 | 明确失败，不输出“成功” |
| T-09 | Checkpoint 保存/加载后的相同输入推断 | 同机结果一致（浮点容差范围内） |
| T-10 | MSE-softmax、L1、L2、Dropout 的梯度/状态测试 | **阶段 4** 加入，按对应推导验收 |
| T-11 | Momentum/AdaGrad/Adam 的首步、多步与状态独立性 | **阶段 4** 加入；与手算/独立 NumPy 参考一致 |
| T-12 | train/val/test 数据泄漏回归检测 | 确保预处理 fit、checkpoint 选择、test 访问流程正确 |

**有限差分定义**：对某个参数 `θ_i`，`g_num = [J(θ_i+h)−J(θ_i−h)]/(2h)`；在 `float64` 下试 `h=1e−5`，要求 `abs(g_num−g_bp) <= 1e−7` **或** `abs(g_num−g_bp)/max(1e−8, abs(g_num)+abs(g_bp)) <= 1e−4`。这是一套可操作的初始阈值，并非普适数学定理；如果失败，要调查步长、ReLU 非光滑点及精度问题，禁止单纯放宽测试让其变绿。检查时禁用 Dropout 或固定相同 mask，关闭非确定性增强。

**异常场景**：loss 上升不必自动断言实现错误，需结合学习率/梯度范数判断；出现非有限 loss/grad/weights 时应立即中止该 run、记录 epoch/step/配置并保留错误证据，不继续输出正常图表。

## 8. 实验矩阵（首轮冻结，不做笛卡尔积）

### 8.1 实验基本方法

实验首先在 **MNIST** 完成方法性对照；随后在 **CIFAR-10** 完成独立基准和少量复验。每组至少保留训练/验证指标、耗时、参数量、配置和 seed；不将课件的 CIFAR 深网络 `3072–1024–512–256–128–64–10` 当作 CPU 基准强制照搬。

| 组别 | 实验编号（预留） | 实验条件 | 数据集 | 目标与优先级 |
|---|---|---|---|---|
| 基线 | B-M | ReLU + CE + 无正则 + mini-batch SGD + 双隐藏层 | MNIST | **P0 必须**，证明完整链路 |
| 基线 | B-C | 适中宽度 MLP + CE + mini-batch SGD | CIFAR-10 | **P0 必须**，挑战实验 |
| 损失 | L-MSE | B-M 的 CE 改为 Softmax-MSE，其它固定 | MNIST | **P1 必须**，附加 1 |
| 正则 | R-L1 / R-L2 / R-DROP | 分别只启用 L1 / L2 / Dropout；B-M 为对照组 | MNIST | **P1 必须**，附加 1 |
| 优化器 | O-MOM / O-ADA / O-ADAM | 固定 B-M 模型、数据和 batch，优化器分别替换 | MNIST | **P1 必须**，附加 2 |
| 优化器扩展 | O-RMS | 与上组条件一致 | MNIST | **P2 预算允许** |
| batch 策略 | D-ONLINE / D-BATCH / D-MINI | 同一 MNIST 训练子集上 B=1 / 全子集 / 代表性中等 batch | MNIST 子集 | **P1 必须完成代表性受控实验**；不可冒充全量效果 |
| 结构 | A-SHALLOW / A-DEEP | 相同数据、统一预算下较浅/较深模型对照 | MNIST | **P2**，展示容量差异 |
| 跨数据集复核 | X-OPT / X-REG | 仅选定一个具有解释价值的优化器对照和一个正则组 | CIFAR-10 | **P2 推荐**，避免单数据集结论泛化 |
| 稳健性 | S-SEED | 选 1–2 关键配置重复 3 个训练 seed | MNIST | **P2**，根据 CPU 预算执行 |

**P0 + P1 是目标交付核心，P2/P3 受资源与截止时间约束**。实验编号只是计划，不意味着已经执行；除基准与 P1 对照外，不因数量庞大而牺牲数据验证与报告分析。

### 8.2 公平比较规程

1. **固定条件**：同一对照组使用完全相同的 train/val 划分、网络结构、预处理、初始化 seed、训练预算口径；改变损失/正则时优化器先固定，改变优化器时损失/正则固定。各实验原始配置快照不可覆盖。
2. **预算口径**：核心优化器对比使用相同数据样本数、epoch 数和 mini-batch 组成/顺序；记录 `optimizer_steps`、samples_seen 和 wall time。batch 策略试验的 step 数天然不同，需要同时报告样本遍历量与更新时间次数，不制造“完全等价”结论。
3. **学习率处理**：不同算法“强行共用一个 learning rate”不能构成充分公平对比。主表采用**每个算法相同数量的预先给定学习率候选试验**（例如各 2–3 个、根据验证集择优）；另可补同学习率可控展示，且注明其局限。候选列表与选择规则在试验前写进配置。
4. **损失对比**：CE/MSE 原值的尺度不同；统一用 `val_accuracy` 和 `val_ce`，并单独绘各自训练 objective 曲线。比较达标 epoch/step 时阈值必须基于**共同度量**。
5. **正则对比**：L1/L2/Dropout 采用一个固定 baseline，分别列出候选正则强度。不能对正则组进行了额外大量调参却直接与未经同等调参的 baseline 比“算法本身优越”。
6. **重复与统计**：最少单次 run 标明 seed；3 seed 仅用于关键实验，报告均值/标准差需有原始记录。没有多次重复不声称统计显著。
7. **测试集**：不参与筛参。最终测试表只包含已经冻结设置的代表模型；所有测试结果清楚对应 checkpoint ID。

### 8.3 绘图和结论的必要输出

- 基线：epoch–train/val Accuracy、epoch–data loss、最终混淆矩阵；关键错分样例可用原图展示但不用于再次调参。
- 损失/正则：至少有可直接对照的验证 Accuracy/CE、过拟合差距及训练耗时表；区分 L1/L2 的数值惩罚与 Dropout 的训练态噪声。
- 优化器：按 epoch 和 optimizer step 的曲线分别展示（如适用）；收敛阈值基于相同验证指标；报告学习率搜索规模、耗时、最终性能。
- CIFAR-10：明确是展平像素上的 MLP，不与未实际训练的 CNN 结果比较或暗示胜过 CNN。
- 对任何效果相反、未收敛或训练失败的案例，保存失败记录并解释，不删除不利实验来制造预期结论。

## 9. CPU 预算与性能基准规则

### 9.1 训练参数只是首轮候选

| 参数 | MNIST 初始候选 | CIFAR-10 初始候选 | 是否已确认 |
|---|---|---|---|
| 网络 | 784–128–64–10 | 3072–256–128–10 | 初始基线冻结；可按性能登记调整 |
| batch size | 128 | 128 | 候选 |
| epochs | 12 | 15 | 候选，不是最低/最高教师要求 |
| CE 优化器 | Mini-batch SGD | Mini-batch SGD | 冻结 |
| LR | 0.05 起测 | 0.01 起测 | 必须通过初测调节 |
| dtype | float32 训练、float64 梯度检查 | 同左 | 冻结 |
| test 使用 | 最终冻结后使用 | 同左 | 冻结 |

**预留决策过程**：阶段 1 用玩具数据和 MNIST 小子集进行正确性验证；阶段 2 在 2,048–5,000 MNIST 样本上做 `100 optimizer steps` 的基准，记录 warm-up 和稳定运行的吞吐；阶段 3 用 2,048–5,000 CIFAR-10 样本重复；根据 `samples/sec` 和实际 epoch 时长确定正式训练预算。BLAS 线程数、CPU 型号、内存等信息写入环境日志。

**默认资源治理线（内部建议，非教师要求）**：单个正式 CPU run 的目标控制在约 **45 分钟内**；总实验训练预算优先规划在 **6 小时量级**，允许用户按时间、电脑性能、DDL 调整。如果估算超预算，按顺序压缩 P2→缩小宽度/epoch（重新统一控制变量）→减少搜索候选；**不**删减 P0/P1 的数学正确性、真实执行记录与附加题必要对照。

可选加速：向量化、合理 batch size、减少不必要的整数组复制、读取时保留 uint8、避免绘图驻留训练进程；不为“速度”改变训练样本集合却不披露。性能对比在同台电脑、尽量相同线程/电源条件运行，报告 `wall clock` 仅是该设备的观测，不宣称普适加速比。

### 附录 B：术语统一

- **Epoch**：遍历一次该组实验定义的训练集；**Batch**：一次更新处理的样本集合；**Iteration/optimizer step**：一次参数更新（每个 epoch 的 step 数由 batch size 决定）。
- **Data loss**：模型输出和标签之间的损失；**Regularization loss**：权重惩罚项；**Total loss**：二者相加。
- **Validation**：模型选择与超参数调整；**Test**：冻结模型后的最终泛化评价；**Checkpoint**：某轮的参数快照。
- **P0**：不得删的基础功能；**P1**：本项目覆盖附加题的必要实验；**P2/P3**：满足质量与预算后再扩展。
